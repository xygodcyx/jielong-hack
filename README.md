# 接龙工作台

参考 `school_checkin` 的微信登录与签到流程，独立实现的本地 Web 工作台。优先支持接龙、签到和周期打卡。

## 启动

需要 Bun 1.3+。使用 pnpm 管理依赖，视频与音频校验另外需要 ffmpeg 中的 `ffprobe`。

```sh
pnpm install
pnpm dev
```

打开 [本地工作台](http://127.0.0.1:3210)。默认只监听本机地址。可复制 `.env.example` 为 `.env`，修改端口、监听地址等配置；Bun 会自动加载。

```sh
# macOS，按需安装视频探测工具
brew install ffmpeg
```

## 使用

1. 微信扫码登录，选择“我参与的 / 我发布的 / 我收藏的”。列表支持分页、搜索和类型筛选。
2. 点击“添加任务”，可粘贴 `https://i.jielong.com/fb/2XY9XM9MCY`、短 ID `2XY9XM9MCY` 或数字 `ThreadId`。网站先通过详情接口解析真实 `ThreadId`，再打开表单。
3. 如需修改已提交内容，点击“我的已有记录”，选择本人可编辑的记录。
4. 水印相机接受本地照片，合成时间、地点、经纬度、右下角品牌与“真实时间”标识；也可以关闭水印，直接使用原图。
5. 点击“预览并准备提交”验证表单并上传附件，核对预览后再确认提交。

“水印工作室”可独立使用，照片合成与下载均在浏览器中完成。“演示空间”不发送真实签到，适合测试完整流程。

手动添加的任务集中显示在侧栏的“手动添加”分类，按真实 `ThreadId` 去重，并持久保存到本地 SQLite。保存记录绑定微信账号，刷新页面、重启服务或退出后重新登录同一账号仍然保留；不同账号分别保存。任务详情始终通过当前登录状态读取。

同时支持 `https://jielong.com/s/…` 分享链接：服务端读取公开重定向，得到最终接龙或打卡地址后，再解析真实 `ThreadId` 并保存。分享跳转不携带账号凭证，最多跟随五次官方站点跳转。

图片支持 JPEG、PNG、WebP；支持上传视频、音频、文件和签名图片。位置可以手动填写地址与经纬度，也可以在浏览器授权后读取设备坐标；设备坐标系不做自动转换。常见文本、数字、选项和日期字段提供表单控件，复杂矩阵等字段保留结构化编辑入口，其服务端协议尚未逐类验证。

## 接口适配

| 功能                  | 接口 / 结构                                                      |
| --------------------- | ---------------------------------------------------------------- |
| 微信登录              | 微信二维码轮询、`/api/User/OpenAuth`                             |
| 我的任务              | `/api/Thread/Threads`，参与 `1`、发布 `2`、收藏 `5`              |
| 接龙 / 签到表单       | `/api/FeedBack/GetEditFeedBackRecord`                            |
| 接龙 / 签到新建与修改 | `/api/FeedBack/AttendFeedBack`                                   |
| 打卡表单              | `/api/CheckIn/EditRecordDetail`                                  |
| 打卡新建与修改        | `/api/CheckIn/EditRecord`                                        |
| 水印照片              | `FieldType=25`，照片放入 `RecordValues[].Files`                  |
| 媒体上传              | 新申请 `CosUploadPolicy`，使用临时签名上传 COS，回填完整附件信息 |

打卡单独携带 `DateTarget`、`MinuteTarget`、`IsNameNumberComfirm`，保留字符串记录 ID。修改记录时从当前账号的新响应中获取编辑凭证，并在确认提交前检查表单与原记录是否发生变化。不会复用 HAR 中的 Token、Cookie、临时上传签名或他人记录。

协议依据用户提供的 `version2`、`shuiyin`、`shuiyin-2` 与 `daka` 抓包；HAR 本身没有复制进项目。

## 数据与校验

- 登录凭证与本地暂存附件位于忽略提交的 `.local/`；Cookie 使用 HttpOnly 和 SameSite=Strict。
- 草稿与选中的文件保存在当前浏览器的 IndexedDB；成功提交后清除对应草稿。
- 预览有效期 10 分钟；同一预览重复确认不会重复提交。
- 网络异常导致提交结果不确定时，先到官网核对记录，再决定是否重新提交。
- 本站依照原平台返回的任务权限、开放状态、字段限制与审核结果处理请求。

可用 `JIELONG_DATA_DIR` 指定本地数据目录，`FFPROBE_PATH` 指定媒体探测程序。若自行通过 HTTPS 反向代理部署，设置 `PUBLIC_ORIGIN=https://你的域名`，用于来源检查和 Secure Cookie。

## 开发检查

沿用项目现有 Antfu ESLint 配置。

```sh
pnpm typecheck
pnpm test
pnpm lint
pnpm build
```

测试使用临时数据库、模拟远端接口和独立本地端口，不提交真实记录。真实账号只读联调已覆盖列表、接龙表单、打卡表单和本人记录编辑；实际向接龙管家提交需在网页确认后进行。
